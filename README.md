
# Multi-Store POS System

A full-stack Point of Sale system deployed live across **4 retail branches** 
of a clothing factory in Saudi.

## Overview

Built to replace manual sales tracking across multiple store locations. 
The system handles real-time inventory, sales recording,statistics, and cross-branch 
reporting from a single backend.

## Features

- 🏪 Multi-store support — 4 branches on one system
- 📦 Inventory management per branch
- 🧾 Sales recording and receipt generation
- 📊 Sales reports and analytics
- 🔐 Role-based access (admin / cashier)

## Tech Stack

| Layer    | Technology          |
|----------|---------------------|
| Frontend | React / Next.js     |
| Backend  | Node.js + Express   |
| Database | MySQL               |
| Storage  | Cloudflare R2       |
| Auth     | JWT                 |
